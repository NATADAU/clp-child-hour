# ЦЛП · Стоимость детского часа

Веб-приложение для предварительного расчёта зарплатной составляющей стоимости детского часа в реабилитационно-образовательных услугах (РОУ).

## Использование

Откройте опубликованный сайт или файл `index.html` в браузере. Загрузите четыре типа Excel-файлов:

1. **Детский табель** — детские часы по группе и месяцу.
2. **Педагогические часы по группам за месяц** — часы сотрудника в группе.
3. **Часы педагогов за месяц** — всего часов сотрудника за месяц.
4. **Учебный год 2025–26 зп РОУ** — начисления с ФИО, месяцем и ЦФУ «РОУ».

Можно выбирать несколько файлов одного типа за разные месяцы. В названиях месячных выгрузок желательно указывать месяц и год (например, `11.2025`). Нажмите «Рассчитать» и изучите вкладки **По группам**, **По педагогам** и **Несовпадения**.

## Формула

Для каждого сотрудника, который присутствует в месячном табеле и зарплатной ведомости:

```
Зарплата, отнесённая на группу =
  Начислено сотруднику за месяц × часы сотрудника в группе / все часы сотрудника за месяц

Стоимость детского часа группы =
  Сумма отнесённых на группу начислений / детские часы группы
```

Индивидуальные начисления могут включать премии, отпускные и прочие выплаты, поэтому это **условная оценка зарплатной составляющей**, а не бухгалтерский расчёт фактической полной себестоимости. Страховые взносы и накладные расходы не включаются.

## Контроль сопоставления

- Совпадения ищутся по **месяцу + нормализованному ФИО**, для детских и педагогических часов — по **месяцу + коду группы**.
- Сопоставления по похожим именам не угадываются автоматически.
- Часы с кодами `П`, `БК`, `ОК.ПЕД.` не распределяются по обычным группам.
- Если не найден один из ключевых показателей, запись выводится в «Несовпадения».
- **Одинаковые коды разных групп** (например, две колонки с кодом 03) и разные правила начисления зарплаты требуют отдельной проверки.
- Вывод «Предварительный расчёт» не является подтверждением корректности данных. Перед использованием сверяйте контрольные суммы с исходными ведомостями.

## Публикация через GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment**:
- Source: **Deploy from a branch**.
- Branch: **main**, папка **/(root)**.
- Нажмите **Save**.

После публикации сайт обычно доступен по адресу:
https://natadau.github.io/clp-child-hour/

## Безопасность

**Никогда не загружайте реальные зарплатные ведомости, детские табели, ФИО детей или готовые отчёты с персональными данными в публичный GitHub-репозиторий.**

Обработка происходит внутри браузера пользователя. Для чтения и экспорта XLSX используется библиотека SheetJS, загружаемая с публичного CDN. При работе с конфиденциальными данными соблюдайте внутренние требования организации.

## Технически

Одна статическая страница `index.html`; сервер и база данных не нужны. Требуется интернет для загрузки библиотеки XLSX.

# ЦЛП — стоимость детского часа

Веб-приложение для оценки **зарплатной составляющей стоимости одного детского часа** в реабилитационно-образовательных услугах (РОУ) Центра лечебной педагогики.

**Сайт:** https://natadau.github.io/clp-child-hour/

## Учётный период

**Учебный год — с 1 сентября по 30 июня включительно (10 месяцев).** Например, 2025–2026 учебный год — с сентября 2025 по июнь 2026.

Июль и август **не входят** в расчёт учебного года, даже если они содержатся в зарплатной выгрузке.

Годовой итог вычисляется по сумме показателей за 10 месяцев, а не усреднением месячных тарифов:

```
Стоимость детского часа за год =
  Сумма зарплатных затрат, отнесённых на группу за сентябрь–июнь
  / Сумма детских часов группы за сентябрь–июнь
```

Годовой итог необходимо явно помечать как **неполный**, если отсутствуют отчёты хотя бы за один из десяти месяцев или есть нерешённые несопоставления.

## Необходимые Excel-отчёты

| Отчёт | Для чего нужен | Периодичность |
| --- | --- | --- |
| Детский табель | Детские часы в каждой группе | Ежемесячно, сентябрь–июнь |
| Педагогические часы по группам за месяц | Часы каждого педагога в каждой группе | Ежемесячно, сентябрь–июнь |
| Часы педагогов за месяц | Все часы сотрудника — знаменатель распределения его зарплаты | Ежемесячно, сентябрь–июнь |
| Учебный год 2025–26 зп РОУ | Начисления сотрудников по месяцам и ФИО с ЦФУ «РОУ» | Один файл за учебный год либо соответствующие выгрузки |

Дополнительный «Отчёт по педагогическим часам» полезен для сверки и выяснения причин расхождений, но в базовую формулу не входит.

## Порядок работы

1. Откройте приложение в браузере.
2. Загрузите файлы **каждого из четырёх видов**. В текущей версии допускается выбор нескольких файлов в каждом поле.
3. Для ежемесячных выгрузок используйте понятное имя с месяцем и годом, например `Детский табель (11.2025).xlsx`.
4. Нажмите **Рассчитать**.
5. Проверьте раздел **Несовпадения**, особенно пропущенные начисления, отсутствующие детские часы и неоднозначные группы.
6. Скачайте Excel с расчётами по группам и педагогам.

## Методика

Приложение сопоставляет месяцы, нормализованные ФИО сотрудников и коды групп. Начисления нескольких строк одного сотрудника за месяц суммируются.

```
Начисления сотрудника, отнесённые на группу =
  Все начисления сотрудника за месяц
  × педагогические часы этого сотрудника в группе
  / все часы сотрудника за месяц

Зарплатная составляющая стоимости детского часа группы =
  Сумма распределённых начислений сотрудников группы
  / детские часы группы
```

Детские часы группы нельзя суммировать отдельно по каждому её педагогу: это приводит к повторному учёту.

Автоматическое распределение зарплаты пропорционально часам — **управленческая оценка**, а не точное бухгалтерское распределение затрат. Начисления могут включать премии, отпускные и выплаты за работу, не относящуюся непосредственно к занятиям. Страховые взносы, содержание помещений, управление и другие накладные расходы здесь не включены. Итог нельзя называть полной себестоимостью услуги.

## Контроль качества данных

- Не угадываем ФИО и коды групп по сходству: нераспознанные и отсутствующие совпадения попадают в раздел «Несовпадения».
- Не распределяем расходы сотрудников, для которых отсутствуют соответствующие часы либо зарплатные начисления.
- Коды `П`, `БК`, `ОК.ПЕД.` исключены из обычной групповой детализации; порядок распределения этих затрат нужно установить отдельно.
- Одинаковый код в нескольких самостоятельных группах (например, `03`) требует ручной проверки. Одного номера группы для надёжного объединения может быть недостаточно.
- Сверяем суммы групповых и общих часов и контролируем, чтобы один и тот же месяц не был загружен дважды.
- Частичное сопоставление нельзя считать окончательным финансовым результатом.

## Правило расчёта детских часов, относимых к педагогу

**Согласованное допущение:** если на одном групповом занятии одновременно присутствуют несколько педагогов, считается, что **каждый из них работал со всеми присутствовавшими детьми на протяжении всей своей части занятия**. Детские часы каждого педагога рассчитываются отдельно.

- Для занятия, на котором было 5 детей в течение 2 часов и одновременно работали 3 педагога, каждому педагогу относим **10 детских часов**; сумма по трём педагогам равна **30 педагогически-атрибутированным детским часам**, но **объём помощи детям группы остаётся 10 детских часов**, не 30.
- Если педагог работал лишь часть занятия, используем только время его участия. Для индивидуального занятия детские часы педагога равны длительности фактического взаимодействия с конкретным ребёнком.
- В расчёт должны попадать **фактически присутствовавшие дети**, а не списочный состав группы. Пропуски детей не превращаются автоматически в детские часы.
- Для достоверного применения к групповым занятиям нужны дата, группа, время занятия, фактическое присутствие каждого ребёнка и участвовавшие педагоги; совпадение только группы и месяца **недостаточно**.
- Нельзя перемножать месячные итоги педагогических и детских часов, принимать всех детей группы за присутствовавших или без подтверждения считать, что педагоги и дети работали одновременно.
- Служебная, техническая, околопедагогическая деятельность, отменённые занятия и консультации без ребёнка не считаются детскими часами без явного подтверждения в исходных данных.
- Записи без точной привязки педагог ↔ занятие ↔ присутствие ребёнка помечаем «не подтверждено» и не включаем в достоверный итог. Если методика допускает расчётную оценку, она должна отображаться отдельно от подтверждённой суммы.

**Различаем два разных итога:**
1. «Детские часы педагога» — сумма часов всех детей, работавших именно с этим педагогом, с разрешённым повтором одного детского часа между педагогами;
2. «Детские часы группы» — объём помощи детям без дублирования по педагогам.

Эти показатели нельзя механически суммировать или подставлять один вместо другого в формулу себестоимости. Правило относится к запрошенному финдиректором отчёту **«ФИО педагога — группа — детские часы за учебный год»**. Отдельно требуются список руководителей групп и выделение амбулатории, если её классификация будет подтверждена.

**Статус реализации:** текущая опубликованная страница пока **не вычисляет** этот показатель на уровне конкретного занятия; прежняя финансовая модель использует другие месячные агрегаты. Новый алгоритм нужно реализовать и протестировать отдельно, прежде чем называть сайт готовым ответом на запрос финдиректора.


## Разделение направлений: первичный приём и амбулатория

**Подтверждено пользователем (09.10.2026):**
- Код группы **`П` — «Первичный приём»**.
- Код группы **`11` — «Амбулатория»**.
- Остальные коды групп учитываются в основном направлении (при отсутствии дополнительных классификаций).

В отчёте для финансового директора формируем три отдельные вкладки/раздела: **Основные группы**, **Первичный приём (П)**, **Амбулатория (11)**. Во всех разделах сохраняем ФИО педагога, код группы и детские часы за учебный год сентябрь–июнь. Отдельно составляем список руководителей групп и исключений/неоднозначных записей.

**Не теряем данные:** «П» не выбрасывается из расчёта, а переносится из общегруппового представления в отдельный раздел. Для группы 11 аналогично: её показатели не дублируются в основном разделе. Суммарный объём помощи по ЦЛП вычисляется на уровне уникальных детских часов и не должен дублироваться по педагогам.

**Реализовано в интерфейсе:** код `П` теперь учитывается как «Первичный приём», `11` — как «Амбулатория». Можно выбрать направление в фильтре, а при экспорте появляются отдельные листы «Основные группы», «Первичный приём», «Амбулатория» и «Все группы». Показатели не дублируются между тремя профильными листами; «Все группы» — дополнительное представление тех же строк. **Ограничение:** это разделение предварительных денежных расчётов. Детские часы по каждому педагогу на уровне конкретных занятий ещё не реализованы, их нельзя подменять зарплатной сводкой. При отсутствии исходных часов или начислений данные попадут в раздел исключений.


## Уточнения справочника групп (согласовано пользователем 09.10.2026)

| Код в выгрузке | Решение |
|---|---|
| `05` и `05.1` | Полностью **исключить из расчётов** детских и педагогических часов в рамках текущей модели. Их исключённые значения отразить в журнале исключений. |
| `16`, `16-МЛ` и `16МЛ` | Считать **одной группой 16**, суммируя часы педагогов в эту группу. Сохранять различия исходных обозначений для последующей проверки. |
| `БК` | **Дети без контрактов**; отдельный раздел/лист в исключениях. Возможны нулевые детские часы, но **отсутствие данных не равно нулю**: не подставлять 0 автоматически. |
| `П` | Первичный приём, отдельное направление. |
| `11` | Амбулатория, отдельное направление. |

Эти правила действуют **внутри нашего приложения**, а не означают, что записи исходных табелей исправлены. Исключённые часы не перераспределяются автоматически. «БК» не включается в денежный расчёт до подтверждения детских часов и методики учёта.

**Ограничение:** объединение `16-МЛ` с `16` по групповой метке не доказывает, что это идентичные занятия. Показатель «детские часы каждого педагога» по-прежнему требует привязки к фактическому присутствию детей на конкретном занятии.

# ЦЛП — стоимость детского часа

Приложение: https://natadau.github.io/clp-child-hour/

## Задача

Оценить **расходы на оплату труда в расчёте на один детский час** по группам за выбранный месяц или за учебный год (сентябрь 2025 — июнь 2026). Это **не полная себестоимость** и не стоимость часа работы группы.

## Всего три источника

1. **01 — Детский табель.** Время занятий детей по группам, датам и детям; используется как знаменатель в детских часах.
2. **02 — Отчёт по педагогическим часам.** Подробные записи о занятиях педагогов; используется для определения долей их времени по группам.
3. **03 — Начисления РОУ.** Годовая или помесячная ведомость начислений; используется для расчёта распределяемых затрат на оплату труда.

Отчёты «Педагогические часы по группам» и «Часы педагогов за месяц» **не требуются** для новой упрощённой версии. Более ранние записи README о пяти источниках устарели.

## Как пользоваться

Выберите «Весь учебный год» или конкретный месяц. Для месяца загрузите отчёты 01 и 02 только за него, а также ведомость начислений РОУ. Для года — 10 табелей каждого вида и начисления за соответствующие месяцы. Нажмите «Рассчитать», откройте «Стоимость часа, ₽» и ознакомьтесь с «Замечаниями». По необходимости скачайте Excel.

## Метод расчёта

- Уникальные детские часы считаем из детского табеля, без умножения на количество педагогов.
- Часы труда педагога не увеличиваются от числа детей: один час работы с пятью детьми — один педагогический час.
- При расчёте долей зарплаты сотрудника по группам берём **только его подходящие занятия** (из подробного отчёта) и распределяем **все распознанные начисления РОУ за месяц** пропорционально длительности этих занятий.
- Полученную сумму по группе делим на детские часы этой группы.

**Ограничение модели:** поскольку теперь не используется сводный табель всех оплаченных часов сотрудника, модель относит всю месячную сумму его начислений на подходящие занятия. Это упрощённая **управленческая оценка**, а не бухгалтерски подтверждённые затраты исключительно на проведение занятий. В зарплате могут быть оплачены консультации, документация, отпускные и иная работа. Уберите эти суммы или используйте подробную схему с полной проверкой для официального финансового расчёта.

Если начисления сотрудника не сопоставились, финансовая вкладка отмечает результат как неполный и показывает процент сопоставленных часов. **Неполную оценку нельзя трактовать как точную стоимость.**

## Принятые исключения

Коды групп `05`, `05.1`, `П` (первичные приёмы) и `ОК.ПЕД.` исключаются. `16-МЛ` объединяется с `16`. Амбулатория `11` и дети без контрактов `БК` показываются отдельно. В подробном отчёте используются только занятия `GRP` и `IND`. Консультации и другие виды служебной работы не участвуют в подсчёте часов занятий.

Присутствие конкретного ребёнка на конкретном групповом занятии определяется приближённо по дате и группе; прямого подтверждения почасового совпадения в этих таблицах нет. Поэтому отчёт «детские часы педагога» тоже оценочный.

## Защита данных

Не размещайте персональные сведения детей или зарплатные ведомости в публичном репозитории. Приложение работает в браузере, использует библиотеку SheetJS, загружаемую через внешний CDN. Результат проверьте на исходных данных перед использованием в финансовых решениях.

## Подтверждённые соответствия ФИО для расчёта (11.10.2026)

При сопоставлении подробного отчёта с начислениями РОУ применяется нормализация пробелов/точек и подтверждённые пользователем соответствия:
- Вандышева (Коломыцева) А. А. = Вандышева А. А.
- Гаева В. А. = Гаева В. А. (Савина В. А.)
- Новичкова Д. = Новичкова Д. С.
- Питрюк М. = Питрюк М. А.
- Семенюк О. И. = Семенюк О.И.
- **Криворог Е. Ю. = Дикова В. Б. (Криворог Е.)** — по прямому указанию пользователя, несмотря на разницу инициалов.

**Битова А. Л. и Битова В. А. — разные сотрудники.** Другие сотрудники не объединяются только по сходству фамилий. Соответствия влияют исключительно на распределение начислений, а не на исходные имена в отчёте по часам.

## Догрузка файлов

Можно загружать ежемесячные файлы № 01 и № 02 несколькими подходами. Повторный выбор **добавляет** файлы к уже выбранным; повторный выбор того же месяца **заменяет** прежний файл данного месяца. Это позволяет заменить, например, пустой октябрьский табель без повторной загрузки остальных девяти месяцев. В каждой карточке показаны сохранённые имена файлов, отсутствующие месяцы и кнопка «Очистить этот набор». Начисления РОУ добавляются по названию файла. Все выбранные файлы хранятся в памяти открытой страницы; при её обновлении или закрытии список сбрасывается. После догрузки нажмите «Рассчитать» ещё раз.

## Автоматическое определение периода (11.10.2026)

Переключатель месяца/учебного года убран. Приложение само определяет периоды по именам загруженных файлов № 01 и № 02 и рассчитывает **только месяцы, за которые имеются оба вида отчётов**. Один совпавший месяц — расчёт за месяц, десять — за весь учебный год, несколько — за выбранные данные. Отчёты можно догружать и заменять по месяцу. При отсутствии файла-пары приложение показывает предупреждение под соответствующим набором, а в «Замечаниях» указывает месяцы вне расчёта. Отсутствующий месяц нельзя воспринимать как нулевые часы. Название экспортируемого Excel зависит от числа вошедших месяцев. Ранее приведённая инструкция о ручном выборе периода устарела.

Кнопка «Рассчитать» сразу показывает подтверждение нажатия, а после запуска — текущий этап или ошибку. При успешной инициализации отображается сообщение о готовности приложения. ## Амбулатория (код 11) — отдельный учёт

По уточнению пользователя амбулатория — **разовые индивидуальные консультации детей**. Код `11` исключён из основного расчёта стоимости детского часа регулярных занятий: детские часы этой категории не входят в знаменатель, а зарплатные начисления, пропорционально отнесённые на работу в амбулатории, не добавляются к основным группам. При распределении месячных начислений часы амбулатории остаются в общем объёме учтённых занятий педагога, поэтому исключение этой категории **не приводит к искусственному перераспределению её доли зарплаты на остальные группы**.

Часы по коду `11` сохраняются в таблицах по педагогам и месяцам для возможного отдельного анализа. Другие индивидуальные занятия (тип `IND`) автоматически не исключаются. Распределение начислений по часам по-прежнему является оценкой.

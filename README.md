# ЦЛП · Детские часы по педагогам и группам

**Приложение:** https://natadau.github.io/clp-child-hour/

Цель: подготовить для финансового директора Светы **годовую таблицу «ФИО педагога — группа — детские часы за учебный год»**, а также список руководителей групп, амбулаторию и список проблемных сопоставлений.

## Период

Учебный год **2025–2026**, с сентября 2025 по июнь 2026, всего **10 месяцев**. Июль и август не включаются.

## Нужны четыре отчёта из «Интерина»

| № | Отчёт | Назначение | Файлов |
|---|---|---|---:|
| **01** | Детский табель | Посещаемость и минуты каждого ребёнка по датам и группам | 10 |
| **02** | Отчёт по педагогическим часам | Подробные занятия педагога: дата, группа, тип, фактические минуты | 10 |
| **03** | Педагогические часы по группам | Руководители групп и вспомогательный контроль состава | 10 |
| **04** | Часы педагогов за месяц | Сводный контроль нагрузки | 10 |

**Зарплатная ведомость не нужна и в новую версию приложения не загружается.** Задача финансового директора — получить часы для дальнейшего самостоятельного расчёта себестоимости, а не стоимость в рублях.

## Как пользоваться

1. Под каждым номером 01–04 выберите все месячные файлы за сентябрь–июнь.
2. Имена выбранных файлов сразу отображаются в соответствующих карточках. Проверка по именам показывает пропуски и дубли месяцев.
3. Нажмите «Рассчитать за учебный год».
4. Просмотрите «Замечания». Итоги являются **расчётной оценкой**, а не подтверждённым почасовым журналом контактов.
5. Скачайте годовой Excel с вкладками «Год педагоги», «Основные группы», «Амбулатория», «Без контрактов», «По месяцам», «Руководители», «Замечания».

## Принцип расчёта — строго различаем показатели

**Педагогические часы:** если педагог работал один час с пятью детьми, его нагрузка — **1 педагогический час**, а не 5.

**Детские часы педагога:** если на том же часовом занятии было пять детей, преподавателю можно приписать **до 5 детских часов по согласованному допущению**. Когда несколько педагогов одновременно работали с теми же детьми, часы могут повторяться в показателях каждого педагога. **Не суммируйте эти часы между педагогами как уникальный объём помощи детям.**

В текущей модели берём из отчёта № 02 педагогические записи типов `GRP` и `IND` с положительными фактическими минутами. Для каждой даты, группы и педагога суммируем длительность групповой работы, а по индивидуальной учитываем конкретного ребёнка. Из отчёта № 01 получаем минуты ребёнка за эту дату. Оценка для каждого ребёнка по конкретному педагогу ограничена сверху временем ребёнка в этот день. Затем суммируем по месяцам и за год.

### Критическое допущение

**Детский табель не доказывает присутствия ребёнка именно на том занятии, которое проводил указанный педагог.** Одинаковые дата и группа не подтверждают совпадения начала, окончания и состава конкретного занятия. Модель предполагает, что каждый педагог работал со всеми детьми группы в период пересечения доступных учётных часов; без почасового регистра это **упрощённая оценка**, а не достоверные детские часы непосредственного контакта. Даже ограничение по ежедневной продолжительности не устраняет этой неопределённости.

Индивидуальные занятия привязываются к ФИ ребёнка из подробного отчёта, но возможны расхождения написания имени, повторные записи и неполная посещаемость. Они требуют проверки.

## Исключения и классификация

- Группы **05 и 05.1** исключаем полностью.
- **16-МЛ** и **16МЛ** приводим к группе **16**.
- **П** — первичный приём, **исключаем** из расчёта.
- **11** — амбулатория, показываем отдельно.
- **БК** — дети без контрактов, отдельный раздел, ноль часов автоматически не подставляем.
- **ОК.ПЕД.** исключаем. При обработке подробного отчёта используем только занятия типов `GRP` и `IND`; консультации (`CNS`), технические и иные записи не включаем. Записи с явно указанными консультациями, технической работой или картами дополнительно пропускаются по ключевым словам. Текстовые метки неполны и могут не отразить все служебные работы.

## Назначение вкладок результата

- **Год педагоги:** главная таблица для Светы, ФИО, группа, оценочные детские часы и педагогические часы.
- **Основные группы:** тот же итог без отдельной амбулатории и БК.
- **Амбулатория:** код 11.
- **Без контрактов:** код БК.
- **По месяцам:** суммы по педагогам и группам за каждый месяц.
- **Руководители:** сведения из отчёта 03, по месяцу и группе.
- **Замечания:** неполные/непрочитанные данные и отдельные расхождения.

## Что необходимо проверить до официальной отправки Свете

1. Корректность распознавания всех десяти месяцев и всех четырёх видов отчётов.
2. Единое написание ФИО, кодов групп, объединение 16 и 16-МЛ.
3. Группы с несколькими руководителями или одинаковым номером.
4. Соответствие конкретных занятий и детского присутствия. Без дополнительной информации часы **остаются оценочными**.
5. Исключения консультаций, первичных приёмов, технических часов и карт.
6. Отсутствие повторных выгрузок и дублей записей.

**Статус:** версия переработана под исходную задачу. Корректность расчёта по реальным годовым файлам ещё не подтверждена пользовательской сверкой; результат нельзя называть окончательным без неё.

## Конфиденциальность

Не публикуйте детские табели, подробные ведомости занятий и готовый отчёт с персональными данными в открытом GitHub-репозитории. Обработка выполняется в браузере, без сервера приложения. Для чтения и экспорта Excel используется SheetJS с внешнего CDN, поэтому соблюдайте внутренние требования информационной безопасности организации.

Статическая страница `index.html`, размещённая через GitHub Pages, без собственной базы данных.

## Дополнительный финансовый раздел — стоимость детского часа

Приложение содержит **два разных результата**:
1. Основной годовой отчёт для Светы: **педагог → группа → расчётные детские часы педагога**.
2. Дополнительный расчёт **стоимости одного уникального детского часа по группе в рублях**.

Для второго результата можно загрузить **необязательный пятый файл** — начисления зарплаты РОУ. Без него отчёт по часам работает.

Предварительная методика финансового раздела: для каждого совпавшего сотрудника и месяца начисления распределяются между группами пропорционально часам его занятий, по отношению к общему количеству его часов из отчёта 04. Затем затраты группы за учебный год делятся на **уникальные детские часы группы** из отчёта 01, без умножения на количество педагогов.

Финансовый показатель пока **оценочный и неполный**, если не установлены соответствия сотрудников, начислений или часов. Он **не является полной фактической себестоимостью**: не учитывает страховые взносы, аренду, хозяйственные расходы и другие затраты; в начисления могут входить премии и отпускные. При совпадении ФИО по-разному написанных в двух выгрузках результат может быть неполным. Не использовать без сверки бухгалтерией.

**Обновление 11.10.2026:** интерфейс снова содержит пятый необязательный источник и вкладку «Стоимость часа, ₽». Упоминание выше о том, что зарплатная ведомость не загружается, относилось к предыдущей версии и более не действует.
